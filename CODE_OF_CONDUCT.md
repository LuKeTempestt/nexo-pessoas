# Código de Conduta

Este projeto espera colaboração profissional, respeitosa e objetiva. Críticas
devem se concentrar no código e nas decisões, nunca na pessoa. Assédio,
discriminação, exposição de dados pessoais e publicação de credenciais não são
aceitos.

Problemas de segurança devem seguir o canal privado descrito em
[SECURITY.md](./SECURITY.md). Outros comportamentos inadequados podem ser
reportados de forma privada ao mantenedor pelo perfil do GitHub. O mantenedor
pode editar, ocultar ou remover conteúdo e restringir a participação quando
necessário para proteger a comunidade e o projeto.
